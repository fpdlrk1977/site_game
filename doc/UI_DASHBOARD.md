# UI_DASHBOARD: 대시보드 및 프로젝트 관리 명세

에디터 진입 전 사용자가 거치는 모든 화면의 컴포넌트 및 동작 규칙을 정의한다.

---

## 1. 라우트 구조

```
/               → 로그인 상태 확인
                  로그인 O → /dashboard 리다이렉트
                  로그인 X → /login 리다이렉트

/login          → 로그인 페이지 (Supabase Auth)
/dashboard      → 프로젝트 목록 (메인 대시보드)
/dashboard/new  → 신규 프로젝트 생성 모달 (별도 페이지 X, 대시보드 위 모달)
/editor/[projectId]/[sceneId]  → 에디터 (대시보드에서 씬 선택 시 진입)
```

---

## 2. 로그인 페이지 (`/login`)

- Supabase Auth UI 컴포넌트 사용 (이메일/비밀번호, Google OAuth)
- 로그인 성공 시 `/dashboard`로 리다이렉트
- 비로그인 상태에서 `/dashboard` 또는 `/editor/*` 접근 시 `/login`으로 강제 이동
- `/space/:sceneId` (뷰어)는 인증 없이 접근 가능 (공개)

---

## 3. 대시보드 페이지 (`/dashboard`)

### 레이아웃

```
┌─────────────────────────────────────────────────┐
│  [로고]           [내 계정]  [로그아웃]           │  ← 상단 네비게이션 (64px)
├─────────────────────────────────────────────────┤
│                                                 │
│  내 프로젝트                [+ 새 프로젝트]       │  ← 섹션 헤더
│                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│  │  썸네일  │  │  썸네일  │  │    +     │      │
│  │          │  │          │  │  새 프로  │      │
│  │  프로젝트명│  │  프로젝트명│  │  젝트    │      │
│  │  씬 N개  │  │  씬 N개  │  │          │      │
│  └──────────┘  └──────────┘  └──────────┘      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 프로젝트 카드 동작
- 카드 클릭 → 해당 프로젝트의 **기본 씬**(`default_scene_id`)으로 에디터 진입
- 카드 우클릭 또는 `...` 메뉴 → [이름 변경 / 씬 관리 / 삭제]
- **씬 관리** 클릭 → 씬 목록 드로어(Drawer) 표시 (섹션 4 참조)
- 프로젝트 없을 때 → 빈 상태 안내 + "첫 프로젝트 만들기" 버튼 표시

### 신규 프로젝트 생성 모달
- `[+ 새 프로젝트]` 버튼 클릭 시 모달 표시
- 입력: 프로젝트 이름 (필수)
- 확인 클릭 시:
  1. `projects` 테이블에 행 삽입
  2. 기본 씬 (`scenes` 테이블) 자동 생성 (`name: 'Scene 1'`, 빈 `scene_data`)
  3. 해당 씬의 에디터로 즉시 이동

---

## 4. 씬 관리 드로어 (Scene Manager Drawer)

대시보드에서 프로젝트 카드의 `...` → [씬 관리] 클릭 시 우측에서 슬라이드인.

### 레이아웃

```
┌───────────────────────┐
│  프로젝트명  [X]       │
│  씬 목록               │
│  ─────────────────    │
│  ● Scene 1  [편집][⋮] │  ← 기본 씬 (●표시)
│    Scene 2  [편집][⋮] │
│    Scene 3  [편집][⋮] │
│                       │
│  [+ 씬 추가]          │
└───────────────────────┘
```

### 동작 규칙
| 액션 | 결과 |
|---|---|
| `[편집]` 클릭 | 해당 씬의 에디터로 이동 |
| `[⋮]` → 이름 변경 | 인라인 이름 편집 |
| `[⋮]` → 기본 씬으로 설정 | `projects.default_scene_id` 업데이트 |
| `[⋮]` → 복제 | 씬 데이터 복사하여 새 씬 생성 |
| `[⋮]` → 삭제 | 확인 모달 후 삭제 (기본 씬은 삭제 불가) |
| `[+ 씬 추가]` | 빈 씬 생성 후 에디터로 이동 |

---

## 5. 에디터 내 씬 전환

에디터 상단 `ViewportToolbar`에 씬 전환 드롭다운 추가.

```
[Translate] [Rotate] [Scale]  |  Scene 1 ▼  |  [저장] [미리보기]
```

- 드롭다운 클릭 → 현재 프로젝트의 씬 목록 표시
- 다른 씬 선택 → 현재 씬 저장 확인 후 에디터 씬 교체
- `[+ 새 씬]` 항목 포함 → 씬 추가 후 즉시 전환

---

## 6. 뷰어의 씬 간 이동

뷰어에서 씬 간 이동은 `EventSchema`의 `action: 'open_url'`을 통해 구현한다.
- 에디터에서 이동 대상 오브젝트의 이벤트를 `action: 'open_url'`, `value: '/space/OTHER_SCENE_ID'`로 설정
- 별도의 씬 전환 전용 액션 타입은 Phase 3에서 `action: 'go_to_scene'`으로 추가 고려

---

## 7. 프로젝트 설정 페이지

대시보드 카드 `...` → [프로젝트 설정] 또는 에디터 내 설정 아이콘 클릭 시 접근.

| 설정 항목 | 설명 |
|---|---|
| 프로젝트 이름 변경 | 인풋 |
| 커스텀 도메인 연결 | 도메인 입력 + DNS CNAME 안내 (FEAT-DOMAIN-01) |
| 임베드 코드 복사 | 스니펫 표시 + 복사 버튼 (FEAT-EMBED-01) |
| Event Bridge 가이드 | 이벤트 수신 코드 예시 표시 (FEAT-BRIDGE-01) |
| 프로젝트 삭제 | 확인 모달 후 삭제 |
