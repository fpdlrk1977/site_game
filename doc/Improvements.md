# 개선 제안 — 사용자 편의(UX) & 디자인(UI)

> 사용자 관점에서 본 현재 프로젝트의 문제점·보완점. **카메라·액추에이터 제외**(별도 명세 `CAMERA.md`·`PIVOT_MANIPULATION.md`).
> 코드 전반을 검토한 실제 관찰 기반. "서비스는 사용자가 살린다" — 편의와 디자인 우선.

## 이미 잘 되어 있는 것 (기반)
토큰 시스템(`globals.css`) · 다크퍼스트 · lucide 아이콘 통일 · 점진적 공개(접이식 섹션) · 빈 상태 코칭 · 커맨드 팔레트 · Undo 엔진 · 떠있는 패널. → 아래는 "여기서 한 단계 더".

---

# A. 사용자 편의 (UX)

### 1. 발견성(Discoverability) — 최대 약점
- 프리팹·배열·불리언·모션·이벤트 등 강력한 기능이 컨텍스트 메뉴·단축키·팔레트 안에 숨어 있음. 신규 사용자는 "상자 놓기" 이상을 못 찾음.
- **보완**: ①우클릭 컨텍스트 메뉴 전면화(PIVOT 근간과 통합) ②툴바에 자주 쓰는 액션(그룹/복제/정렬) 노출 ③"할 수 있는 것" 힌트(빈 상태·첫 오브젝트 후 코치마크).

### 2. 3D 내비게이션이 업계 표준과 다름
- 회전=**Ctrl+좌드래그**. 대부분 도구는 우드래그/Alt/중클릭 기대(사용자도 ctrl+우클릭 회전 기대했다고 기록). 학습장벽.
- **보완**: 우드래그/Alt 회전 옵션 + 뷰포트 내비 안내 + 시점 초기화 노출.

### 3. 안전장치(작업 유실 방지)
- 오토세이브 미결정(수동 Ctrl+S만) · **Undo/Redo 버튼이 툴바에서 주석 처리**돼 숨음 · 저장 충돌 시 "새로고침" 안내(유실 우려).
- **보완**: ①오토세이브 재활성(낙관적 잠금 이미 있음) ②Undo/Redo 상시 노출 ③충돌 시 병합/백업.

### 4. 정보 밀도 과다
- Inspector가 9~11px + 다닥다닥 섹션 → 초보에게 벽. 점진적 공개 있으나 여전히 빽빽.
- **보완**: 기본/고급 분리 강화, 섹션 간 여백, "지금 필요한 것만".

### 5. 라벨 언어 혼재 (UX+디자인 공통)
- "Material/Emissive/Roughness"(영어) + "복셀 수정/회전축(경첩)/게임 변수"(한글)가 한 화면에. 힌트는 한글인데 제목 영어 → 혼란.
- **보완**: **한 언어로 통일**(대상=한국 일반인이면 한글 우선 권장). 지금 "둘 다"가 최악.

### 6. 피드백 / 되돌리기 어려운 액션
- Merge·Boolean·프리팹 해제 등 비가역/반쯤 비가역 동작이 토스트만으로 진행.
- **보완**: 파괴적 동작 전 확인/미리보기, 실행 후 "되돌리기" 토스트 액션.

### 7. 성능 체감
- 숫자 입력 스크럽 시 캔버스 전체 리렌더(기록됨) → 큰 씬 버벅임.
- **보완**: 스토어 selector 분리로 입력 중 캔버스 리렌더 차단.

# B. 디자인 (UI 중심)

### 1. 입력/표면 스타일이 파일마다 제각각 — 최우선
- 같은 입력창인데 `bg-muted/5 dark:bg-muted/10` / `bg-background` / `bg-surface` / `dark:bg-sidebar!` / `dark:bg-muted` 혼용. 통일된 입력 스타일 부재 → 패널마다 달라 보임.
- **보완**: 단일 Input/Select/Button 프리미티브로 강제(하나의 배경·테두리·높이·radius). `ui.tsx`에 일부 있으나 미적용 곳 다수 → 전면 적용.

### 2. 타이포 스케일 부재
- `text-[9px]~[13px]` 혼재. **9px는 가독성 한계 이하**(다크 저대비 특히). 라벨/값/힌트 위계가 크기로 안 잡힘.
- **보완**: 3~4단 타입 스케일 고정(예: 라벨12·값13·힌트11·섹션12 semibold). 9px 제거. 위계=크기+색.

### 3. 비표준/깨진 유틸리티 클래스
- Toggle이 안 움직인 원인 = `-top-6/4`(무효)·`w-7.5 h-1`(트랙보다 큰 노브). 이런 무효/이상 클래스가 곳곳에 → 미묘한 렌더 깨짐.
- **보완**: 무효 클래스 감사·정리. 공용 프리미티브 전환 시 자연 소멸.

### 4. 색/선택 일관성
- **선택색이 라이트=파랑(#0d99ff)·다크=초록(#008a25)** — 테마마다 "선택" 정체성이 달라 브랜드 흔들림.
- muted 투명도(`/50 /60 /70`) 난발 → 위계 흐림·저대비 접근성 우려.
- **보완**: 선택색을 **테마 무관 브랜드색 하나**(바이올렛 계열 권장, primary 조화). muted 단계 2~3개로 규칙화.

### 5. 여백·리듬
- `px-1.5/2/3`·gap 제각각 → 정돈감 약함.
- **보완**: 4/8px 그리드 리듬으로 패딩·갭 통일. 섹션 구분선/여백으로 그룹 명확화.

### 6. 버튼 위계
- 버튼이 파일마다 애드혹(primary/surface/background 혼용) → 주/보조/위험 위계 흐림.
- **보완**: Button 프리미티브 3종(primary·ghost·danger) 통일.

### 7. 컨트롤 디테일
- 16px 컨트롤에 6px radius, range 트랙 4px+thumb 8px 등 미세 불일치.
- **보완**: 컨트롤 크기·radius·thumb를 컴포넌트에서 일괄 정의.

## 우선순위 (임팩트 대비 노력)

| 순위 | 항목 | 왜 |
|---|---|---|
| ★ 즉효 | **입력/버튼/셀렉트 프리미티브 통일 + 타입 스케일 고정** | 전 화면 즉시 정돈(디자인 최대 레버리지) |
| ★ 즉효 | **라벨 언어 통일**(한글 우선 권장) | 혼란 제거, 진입장벽↓ |
| ★ 즉효 | **Undo/Redo 노출 + 오토세이브** | 작업 유실 불안 제거(신뢰) |
| 중 | **선택색 테마 통일 + muted 위계 규칙** | 브랜드·가독성 |
| 중 | **3D 내비 표준화(우드래그 회전) + 안내** | 학습곡선↓ |
| 중 | **컨텍스트 메뉴로 기능 발견성**(근간 작업 통합) | 강력 기능 사용률↑ |
| 후속 | 정보 밀도 완화 · 파괴적 액션 확인 · 성능 selector | 완성도 |

## 결론
가장 레버리지가 큰 것은 **"디자인 시스템 정리 한 번"** — 입력·버튼·타입·색·여백 프리미티브 통일 + 무효 클래스 청소. 이 한 번으로 화면 전체가 프로답게 정돈되고, 이후 새 기능도 자동으로 일관된다. (참고: `doc/UI_REDESIGN.md`에 리뉴얼 방향 존재 — 이 문서는 그 위의 "일관성·편의" 보완.)
